## Key Dependencies

**Critical:**
- `stacked ^3.5.0` - Drives the entire MVVM architecture; routing and DI are generated by `stacked_generator`
- `drift ^2.24.0` - Core offline storage; all local reads/writes go through Drift DAOs
- `workmanager ^0.9.0` - Required for background sync on Android; callback dispatcher runs in isolated Dart isolate

**Infrastructure:**
- `dio ^5.4.0` - All remote API calls
- `connectivity_plus ^6.1.4` - Online/offline state driving sync trigger logic
